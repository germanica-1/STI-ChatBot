This project is a single-page chatbot built with an STI-themed interface and powered by the Google Gemini API,  
designed to provide real-time, AI-driven responses for students and users in a simple and responsive layout.  
The chatbot runs directly in the browser or with minimal backend setupof npm, with environment variables (such as the `GEMINI_API_KEY`)  
this project showcases how modern AI APIs can be integrated into web applications for interactive learning and engagement.
